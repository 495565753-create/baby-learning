# 奇趣口袋

六个原创网页小游戏：星邮快递、旋环工坊、森林搬搬队、车车出逃、泡泡星球、云上叠塔。每款有 5 关，支持手机触控和电脑操作，通关进度保存在当前浏览器中。

另有独立的 [小小闯关乐园](kids.html)，收录 20 款难度稍高的原创小游戏：恐龙跳跳、飞跃小鸟、贪吃小蛇、青蛙过路、迷宫豆豆、星星迷宫、小小推箱工、数字合并、彩色三消、数字拼图、水管连连看、彩盘搬家、彩块叠叠乐、弹球打砖、乒乓小冠军、翻牌大挑战、颜色节奏王、井字棋对决、四子连线、地鼠闪闪抓。点击 `index.html` 中的入口即可进入，也可以直接打开 `kids.html`。

[50 关闯关城](levels.html)新增 5 款进阶解谜游戏，每款 50 关，共 250 关：车车出逃、星星搬运队、迷宫寻宝、水管小工程师、图片拼拼乐。入口位于 `kids.html` 游戏列表顶部。关卡经过自动求解验证；难度逐步提高，支持方向按钮与触屏、撤销、重玩、语音提示和本机进度保存。关卡由 `build_level_data.py` 生成，保存在 `levels-data.js`。

这些游戏没有广告；首次点击三角形开始按钮后播放轻柔循环音乐，操作有短音效，支持的手机还会短暂震动。20 款游戏的玩法说明、胜利鼓励和常见提示均使用统一的本地中文语音文件，不依赖手机系统朗读。游戏选单、开始、重玩、返回、音乐和操作按钮以图标为主；文字玩法说明折叠在“家长说明”中。可切换音乐、重置星星记录。实时动作游戏有失败重试，解谜游戏则可以慢慢思考。

图标取自 [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 的彩色 SVG，按其 MIT 许可使用，完整许可见 `assets/fluent/LICENSE`。语音由 [Kokoro-82M-v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)（Apache-2.0）在本地生成，生成脚本和台词分别见 `generate_kid_voice.py` 与 `voice/scripts.json`。网页播放时不向语音服务发送内容。

## 打开游戏

双击 `index.html`，用浏览器打开即可游玩。所有程序、美术和音效都在本文件夹中，不需要安装依赖，也不需要联网。

如果浏览器不允许直接打开本地文件，可以在这个文件夹运行 `python3 -m http.server 8787`，再访问 `http://localhost:8787`。

## 操作

- **星邮快递**：电脑按 `←` / `→` 或 `A` / `D`；手机按住画面下方的按钮。上坡加速，腾空后适时松开油门。
- **旋环工坊**：点圆环使其顺时针转动，也可以用下方按钮转动选中的环；键盘按 `1`～`4` 选环，方向键转动。
- **森林搬搬队**：点击颜色按钮，或直接点击画布边缘的色块。
- **车车出逃**：点击车辆选中，再按方向按钮；也可以沿车身方向滑动，把红色小车开到出口。
- **泡泡星球**：点击画面瞄准发射，凑齐三个同色泡泡消除；用下方按钮切换颜色。
- **云上叠塔**：看准重合时点击画面或下方按钮放下方块；电脑也可以按空格。

## 后续发布

这是可供体验和验证玩法的本地网页版，目前没有接入广告、收费、用户账户或后台服务。若要公开发布，需要选择网站托管、配置访问域名。若要发布为微信小游戏，需要按微信小游戏环境适配、注册账号并提交审核。
