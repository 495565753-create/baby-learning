# 儿童外部视频来源核查 · 2026-10-04

这次增加的是官方播放页面链接，供家长和孩子点击后去来源网站观看。程序不下载视频、不嵌入第三方播放器、不保存第三方封面，也不把搜索结果页当成视频。

## 选择范围与核查方法

选用央视网《智慧树》已有的儿童科普、生活认知和手工节目片段。央视公开栏目元数据说明该节目面向 3—6 周岁学龄前儿童。没有选用成年 AI 纪录片、战争视频、新闻直播、政治宣传、未经确认授权的转载视频或需要付费会员的链接。

使用网页检索浏览、具体节目页面及两个央视公开元数据端点交叉检查。11 个页面通过严格 HTTPS HTTP 读取，页面标题和节目简介均对应具体选集，而不是搜索页或直播页。所有选集核查时均返回公开可播放的元数据标记：`public=1`、`play=1`、`vip_flag=0`、`is_invalid_copyright=0`、`is_protected=0`。这只证明来源网站当前公开提供内容，不等于已经在所有地区、所有手机或未来版本实测播放成功。

具体接口由节目页公开脚本中的 `guid` 与官方接口引用获得：

- 栏目/题目/适龄/发布时间/目录时长：`https://api.cntv.cn/video/videoinfoByGuid?guid=<guid>&serviceId=tvcctv`
- 播放状态与实际媒体时长元数据：`https://vdn.apps.cntv.cn/api/getHttpVideoInfo.do?pid=<guid>`

程序只保存节目页 URL，不保存 API 返回的媒体播放地址。目录时长与播放器时长有 0—3 秒差异，UI 使用播放器元数据 `video.totalLength` 四舍五入所得的时长。

## 登录、广告、地区及播放限制

- 页面本身无需登录即可读取标题、简介和公开播放器元数据；不是登录跳转页。页面包含登录功能，但不能据此断言播放必需登录。
- 机器人选集目录元数据 `ad=1`；其他选集该字段为空。空字段不意味着无广告，因此统一提示“页面可能有广告或其他推荐”。
- 11 个选集 `vip_flag=0`，未观察到付费会员拦截元数据；不宣传未来永久免费。
- 当前公开播放元数据没有显示版权地区拦截；不保证所有地区网络播放，来源站点也可能更改限制、要求客户端或改版。
- 并未逐秒审看 11 个完整视频；适龄筛选来自官方栏目说明、题目及节目简介，实际来源网站的侧栏推荐与广告不受本站控制，采用“和爸爸妈妈一起看”的简单观看提示。
- 不接入 YouTube 链接，以免普通中国大陆网络无法访问；不绕过地区限制。没有把 B 站搜索页或未经确认的转载作为素材。
- 这批选集发布于 2019—2023 年，用于理解机器人、打印、自然等基础概念，不称作近两三年新发布的视频。AI、短视频平台、国家等新认知由原创认知卡片独立解释。

## 数据与首页建议

`kids-videos-data.js` 导出数组 `window.KIDS_VIDEOS`、4 项数组 `window.KIDS_VIDEO_CATEGORIES`（`science/nature/life/craft`）和简短字符串 `window.KIDS_VIDEO_NOTICE`。条目包含 HTTPS 节目页、来源名称、真实源标题、发布时间、核查日期、实际时长、儿童简短说明及亲子提问。没有第三方图片 URL。

首页以大图标分别提供“听故事 / 认一认 / 上课堂 / 玩游戏 / 画画涂色 / 看视频”；常用功能首屏直达。视频单独进入目录，显示主题、时长及来源，点击以 `target="_blank" rel="noopener noreferrer"` 打开对应节目页，保留本程序页面让孩子容易返回。无需给孩子增加账号或付费流程。
